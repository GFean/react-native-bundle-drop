# Bundle Drop Support

## Questions and troubleshooting

Use [GitHub Discussions](https://github.com/GFean/react-native-bundle-drop/discussions)
for integration questions, troubleshooting, and usage guidance. Include relevant
package, React Native or Expo, platform, and runtime versions. Support is provided
on a best-effort basis without a guaranteed response time.

## Bugs and feature requests

Use the [issue tracker](https://github.com/GFean/react-native-bundle-drop/issues)
for reproducible bugs, focused feature requests, and documentation problems. Search
existing issues and Discussions first, then use the appropriate issue form.

## Security and sensitive information

Report suspected vulnerabilities through the repository's
[private vulnerability reporting](https://github.com/GFean/react-native-bundle-drop/security/advisories/new)
flow. Do not post credentials, signing material, customer data, private endpoints,
or generated build and authentication receipts in Issues or Discussions.
